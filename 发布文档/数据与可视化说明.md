# 知危鉴 · 数据与可视化说明

> 适用版本：v2026.10（含"中国历史灾害事件"学术可视化新增模块）
> 相关代码：`streamlit/zhiweijian/disaster_history.py`（历史事件数据集）、`streamlit/zhiweijian/viz_academic.py`（灾害数据可视化）
> 本文档回答四个问题：**数据从哪来 → 做了什么处理 → 画成什么图 → 为什么这么画**

## 1. 灾害分类标准

### 1.1 国家标准五大类

依据我国《自然灾害分类》（GB/T 28921 框架及应急管理部业务口径），自然灾害划分为五大类：

| 大类 | 定义要点 | 子类清单 |
|---|---|---|
| **气象灾害** | 由大气圈异常活动直接造成的灾害 | 台风（热带气旋）、暴雨/洪涝、干旱、高温热浪、低温冷冻（寒潮/霜冻）、雪灾、冰雹、雷电、大风、沙尘暴、大雾 |
| **地质灾害** | 由岩石圈活动或地质体变形失稳造成的灾害 | 地震、崩塌、滑坡、泥石流、地面塌陷、地面沉降、地裂缝 |
| **水文灾害** | 由水圈异常（河湖/冰情）造成的灾害 | 河流洪水（凌汛）、湖群溃决、内渍、海冰以外的内陆水体冰情 |
| **海洋灾害** | 由海洋水体异常造成的灾害 | 风暴潮、海啸、海浪、海冰、赤潮、海岸侵蚀 |
| **生物灾害** | 由有害生物暴发流行造成的灾害 | 病虫害（蝗灾、草地贪夜蛾等）、鼠害、疫情（动植物疫病）、森林/草原火灾（部分口径归入） |

### 1.2 本库映射表（子类 → 大类）

| 事件子类（本库字段取值） | 归入大类 | 备注 |
|---|---|---|
| 台风 | 气象灾害 | 沿海登陆事件同时计入风暴潮影响评估时单列为海洋口径 |
| 暴雨/洪涝 | **气象灾害** | **约定口径**：本库默认归气象灾害；部分教材将洪涝归水文灾害（河湖水体异常），二者差异在文档与代码注释中均予注明 |
| 干旱 | 气象灾害 | 以气象干旱为主口径，叠加农业干旱影响字段 |
| 高温热浪 | 气象灾害 | — |
| 低温冷冻 / 雪灾 | 气象灾害 | — |
| 强对流（冰雹/大风/龙卷） | 气象灾害 | — |
| 沙尘暴 | 气象灾害 | — |
| 地震 | 地质灾害 | 震级/烈度字段来自 USGS |
| 滑坡 | 地质灾害 | — |
| **泥石流** | **地质灾害** | **约定口径**：泥石流常由暴雨触发，但灾害本体属地质体运动，归地质灾害（有教材将其与暴雨并列为"次生链"事件，本库不采用） |
| 崩塌 / 地面塌陷 | 地质灾害 | — |
| 风暴潮 | **海洋灾害** | 台风引发但成灾介质为海水，归海洋灾害 |
| **海啸** | **海洋灾害** | 震源在地质圈、成灾介质在海水中，按国标归海洋灾害 |
| 海浪 / 海冰 / 赤潮 | 海洋灾害 | — |
| 森林/草原火灾 | 生物灾害 | 按应急管理部综合口径暂列生物灾害大类；学术可视化中如遇样本过少则标注为"其他" |
| 病虫害 / 鼠害 | 生物灾害 | — |

> **三条核心约定**（与代码 `disaster_history.py` 保持一致）：
> 1. **洪涝默认归气象灾害**，注释注明"有教材归水文灾害"的口径差异；
> 2. **泥石流归地质灾害**，暴雨仅为触发因子，本体归地质；
> 3. **海啸、风暴潮归海洋灾害**，不以触发源头（地震、台风）归类。

## 2. 数据来源清单

| # | 数据集 | 来源 | 获取方式 | 主要字段 | 更新频率 | 已知局限 |
|---|---|---|---|---|---|---|
| ① | **中国重大自然灾害编纂事件集** | 应急管理部《全国自然灾害基本情况通报》（年度）、中国气象局、水利部、自然资源部《海洋灾害通报》、USGS 震例页 | 人工编纂为内置结构化数据文件（随 `disaster_history.py` 分发），每条附来源标注 | 事件名称、起止日期、灾害子类、受灾省份（省级行政区）、伤亡人数、直接经济损失（亿元）、震级/台风等级（如适用）、来源引用 | 年度人工更新 | 为重大事件**抽样编纂**而非全量灾情库（2010–2024 年 ≥60 条）；损失数字以官方通报口径为准，不同年份统计口径略有调整 |
| ② | **USGS 地震动态补充** | USGS Earthquake Catalog（FDSN 事件服务） | HTTP GET：`https://earthquake.usgs.gov/fdsnws/event/1/query?format=csv&starttime=<start>&endtime=<end>&minlatitude=15&maxlatitude=55&minlongitude=70&maxlongitude=140&minmagnitude=<M>&orderby=time`；时间窗默认近 30 天（可配置），参数含 M≥4.5 阈值、中国及周边 bbox | 时间、经纬度、震级、震源深度、地点名称 | 每次会话实时拉取 | 依赖外网连通与 USGS 服务可用性；海外周边地震（bbox 覆盖）需按国界二次过滤；缺失中国官方台网测定值 |
| ③ | **台风轨迹** | NHC/CMA 最佳路径数据的内置精简版（源自 IBTrACS 衍生集） | 内置数据文件，按台风编号索引 | 台风编号、名称、时间步、中心位置（经纬度）、近中心最大风速、中心气压、强度等级 | 静态内置，年度补充 | 只收录影响中国的历史台风，非西北太平洋全量；轨迹为最佳路径（事后订正），非实时定强 |
| ④ | **实时天气** | Open-Meteo API | HTTP GET：`https://api.open-meteo.com/v1/forecast?latitude=<lat>&longitude=<lon>&current_weather=true`（免费、免密钥） | 温度、风速、风向、天气代码 | 实时（页面刷新时请求） | 无灾害语义（需前端规则映射预警提示）；单点查询，不构成面状监测；API 可用性受境外服务影响 |

> **数据合规原则**：所有在线数据仅作展示与教学用途，官方灾情数字以应急管理部等原始通报为准；USGS 与 Open-Meteo 为境外服务，生产部署时建议加缓存与降级策略。

## 3. 逐图说明（学术可视化图组 `viz_academic.py`）

通用处理链：**清洗去重 → 时间窗过滤 → 按省空间聚合**。所有面板统一采用分省 choropleth（面状填色），配色遵循论文规范。

| 图号 | 图名 | 数据来源 | 处理链 | 图型与配色 | 制图要素 |
|---|---|---|---|---|---|
| 图 1 | 2010–2024 分省灾害频次分布 | 编纂事件集 ① | 去重（事件名+日期键）→ 限定 2010–2024 窗口 → 事件计数按受灾省聚合 | 分省 choropleth，顺序色带 **YlOrRd**，colorbar 标注"次"，采用分位断点（quantiles）避免极值压缩 | 南海诸岛 inset、面板标号 a |
| 图 2 | 分灾类频次与损失结构 | 编纂事件集 ① | 按 §1.2 映射表归并五大类 → 类内计数与经济损失求和 | 五大类分面板小倍数（small multiples）choropleth，YlOrRd，各面板 colorbar 独立标单位 | 面板标号 a/b/c…、共享图例说明 |
| 图 3 | 年度灾情时间序列（频次/损失双轴） | 编纂事件集 ① | 年份聚合 → 损失按 CPI 提示不做平减（标注名义值） | 折线 + 柱组合图，主色使用学术灰蓝体系，避免红绿对冲 | 坐标轴单位标注、面板标号 |
| 图 4 | 事件损失空间分异（经济损失密度） | 编纂事件集 ① | 损失额按省求和 → 除以省份面积得密度 → 自然断点或分位断点分级 | choropleth，**RdBu_r 发散色带**（以中位数为锚），colorbar 单位"亿元/万km²" | 南海诸岛 inset、hatching（无数据省份打斜线）、面板标号 |
| 图 5 | 地震震级—频次与空间分布 | 编纂事件集 ① + USGS ② | USGS 拉取后 bbox→国界过滤 → 与编纂集震例去重合并 | 底图 choropleth（浅灰 YlOrRd 频次）+ 震中气泡叠加（气泡大小∝震级） | 指北针、比例尺、南海诸岛 inset、面板标号 |
| 图 6 | 典型台风路径与强度 | 台风轨迹 ③ | 按台风编号筛选 → 时间步排序 → 强度分级着色 | 轨迹线图叠加省界底图，强度用分类色标（热带风暴→超强台风离散色带） | 指北针、比例尺、图例含等级色块 |
| 图 7 | 分省灾情分布形态对比 | 编纂事件集 ① | 省级样本抽取 → 频次/损失两组分布 | choropleth 组旁挂 **小提琴图（violin）** 面板，展示省级分布形态；箱线图作中位数参照 | 面板标号 a/b、小提琴图、箱线图 |
| 图 8 | 历史与现代对比（近 15 年 vs 近 3 年） | 编纂事件集 ①（+USGS ② 现势补充） | 双时间窗分别聚合 → 计算变化率 | **RdBu_r 发散色带** choropleth（增=暖、减=冷），colorbar 单位"%" | 南海诸岛 inset、hatching（零样本省）、面板标号 |

> **配色规范**：顺序型变量（频次、损失）统一 **YlOrRd**；发散型变量（变化率、距平）统一 **RdBu_r**；所有 colorbar 必须带物理单位；分级优先采用**分位断点**（quantile breaks），极值敏感指标可改用自然断点。**纯 matplotlib 面状填色、无瓦片底图**。

## 4. 与参考图风格对照

参考的三张 Nature 系图组样张及其要素清单，与本库各图的借鉴对应关系如下：

| 参考图 | 参考图核心要素 | 本库对应借鉴 |
|---|---|---|
| **参考图 A**：美国干旱—热浪四联图（Nature 风格） | 四联小倍数面板；同一事件指标跨年代对比；面板旁挂 **violin（小提琴图）** 展示空间分布形态；面板标号 a/b/c/d；统一顺序色带 | 图 2 的分灾类小倍数结构；图 7 的 violin 挂板设计；全组的面板标号体系与统一色带策略 |
| **参考图 B**：中国九宫格河域图（PNAS 风格） | 九宫格分面；**南海诸岛 inset**（右下角缩略框 + 九段线）；**分类（离散）色标** 与图内要素一一对应；分面共享投影 | 图 6 台风强度**分类色标**的设计依据；全组统一的**南海诸岛 inset** 规范；分面共享投影与图例位置的版式 |
| **参考图 C**：中国 285 市减排归因图 | 市级 choropleth + **hatching（无数据/不显著区打斜线）**；**指北针**；**比例尺**；**Gini 折线**（不平等指标时间序列）；**箱线图** 辅助面板 | 图 4 与图 8 的 hatching 规则（零样本/无数据省）；图 5 的指北针与比例尺；图 3/图 8 对"Gini 折线"思路的迁移——以时间序列折线 + 箱线图呈现空间不平等演化 |

> 归纳而言，本库从参考图组继承了四条版式基因：**① 分省/分市面状填色为骨架；② 南海诸岛 inset 与指北针、比例尺为标配；③ 统计分布面板（violin/箱线）挂靠地理主图；④ 面板标号 + 单位化 colorbar 的论文级标注体系**。

## 5. 合规声明（中国地图制图）

本项目的所有中国地图可视化均遵守以下规定：

1. **领土完整性**：中国地图必须完整包含**台湾省、南海诸岛（含东沙、西沙、中沙、南沙群岛）及九段线**；南海诸岛以右下角 inset 呈现时，主图不得因省略 inset 而出现"地图开口"。
2. **边界数据来源（优先级从高到低）**：
   - 本机**天地图 1:100 万**矢量边界数据（优先，离线可用）；
   - 自然资源部**标准地图服务**（bzdt.ch.mnr.gov.cn）提供的审图号边界；
   - 其次为**阿里 DataV GeoAtlas**（GeoJSON，`https://geo.datav.aliyun.com/areas_v3/bound/`）。
3. **禁用来源**：**禁止使用 Google Maps、OpenStreetMap、Mapbox** 等境外瓦片服务作为底图，也禁止任何瓦片底图叠加。
4. **制图方式**：全部地图采用 **纯 matplotlib 面状填色（choropleth）**，加载本地/审图号 GeoJSON 绘制边界，不调用任何在线瓦片；发布前对照标准地图样图核校边界。
5. **审图要求**：正式出版或公开传播的地图应送自然资源部审核并标注审图号；本项目界面内地图为教学演示用途，仍按上述规范执行。

## 6. 已知局限与后续工作

| 类别 | 现状局限 | 后续计划 |
|---|---|---|
| 编纂事件集 | 为**重大事件抽样**而非全量灾情库，2010–2024 约 ≥60 条，存在选择偏倚（重损失事件更易入选） | 逐步扩充至分年度 10 条以上；引入 EM-DAT 等国际库做交叉校验 |
| 生物灾害 | 样本量少，五大类中生物灾害面板统计意义有限 | 补充农业农村部病虫害通报数据；样本不足时在图中明确标注 |
| 空间精度 | 事件坐标多为**市级精度**，按受灾省聚合可能高估波及范围 | 引入县级样本与受灾范围多边形 |
| USGS 在线依赖 | 地震动态补充依赖外网与 USGS 服务可用性 | 增加本地缓存与超时降级；可切换 CEA/中国地震台网速报目录 |
| 台风数据 | 最佳路径为事后订正，非实时；仅收录影响中国的台风 | 接入 IBTrACS 全量做西太平洋对比分析 |
| 损失口径 | 各年度通报的直接经济损失统计口径略有调整，未做 CPI 平减 | 引入平减指数并注明基期 |
| 地图审图 | 演示地图未申请审图号 | 公开发布前送审并标注审图号 |
