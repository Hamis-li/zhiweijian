### 1.2 存储规范
| 数据类型 | 格式 | 位置 | 命名规范 |
|---|---|---|---|
| 事件/结构化 | **JSONL**（一行一事件） | `data_archive\` | `usgs_<年>.jsonl`（UTF-8，无BOM） |
| 矢量 | SHP/GeoJSON | 本机 E:\ATAIFEN（引用路径，不入库大文件） | 保留官方原名，不改名 |
| 栅格 | TIF/NC | 规划：`data_archive\raster\` | `<要素>_<年月>.tif` |
| 文档 | Markdown | `发布文档\` | 中文名+下划线，禁止空格 |
| 代码 | Python | `streamlit\zhiweijian\`（主）/`backend\`（工程栈） | snake_case |

### 1.3 三条铁律
1. **单一主版本**：一切改动在 `main` 分支原地迭代提交（git），**严禁**复制 `app_v2.py`/`_final_final` 这类版本文件夹。
2. **文档同步**：每改一次代码，必须同步更新 `发布文档` 对应章节（至少改"版本沿革"一行）。
3. **记忆不可丢**：`.workbuddy\memory\` 的 MEMORY.md（星标指令）与日志文件**永不删除**；跨会话靠它衔接。

## 四、代码托管与权限控制（他人只读、本人可写）

现状：仓库 `github.com/Hamis-li/zhiweijian` 目前为 Public。目标：**私有 + 指定协作者只读**。AI 无 GitHub 写权限 token，需你在网页做 **5 分钟一次性操作**：

1. **转私有**：仓库页 → `Settings` → 底部 `Danger Zone` → `Change repository visibility` → **Make private** → 按提示输入仓库名确认。
   - Streamlit Cloud 用你本人账号连接私有仓库，**照常自动部署**，不受影响。
2. **加只读协作者**：`Settings` → `Collaborators` → `Add people` → 输入对方 GitHub 用户名 → 邀请。**私有仓库的协作者默认就是只读（Read）**，除非你显式授予 Write/Triage 角色——即天然满足"他人只读、本人可写"。
3. **本人**保持 Owner（读写+管理）；日后要给某人写权限，才在其邀请角色里手动升 Write。
4. 建议开启：`Settings → Branches → Add rule` 对 `main` 设 Require a pull request before merging=关闭（个人项目单人直推即可），但可勾选 **Do not allow force pushes** 防误操作。

## 五、展示与项目管理

- **实时展示**：Streamlit 在线应用即展示层（在线数据 600s 缓存+预警大屏自动刷新机制已内置）；自动维护的《数据更新日志》《案例与文献库》为阶段性成果流；可再挂 WorkBuddy 资料库（高级版 20GB）做看板沉淀。
- **单一项目承载（评估结论：可行）**：高级版 15 项目/8人协作/20GB/50应用——本项目固定用当前工作区一个项目承载全部（工作区+记忆+发布文档），代码以 GitHub 为唯一事实源，WorkBuddy 侧不另起副本；新需求优先"同一项目内新会话+三步续接法"，而非新建项目。

## 六、多智能体协作与模型调度（低成本自动匹配）

| 任务类型 | 模型档位 | 典型任务 | 成本 |
|---|---|---|---|
| 资料检索/格式整理/翻译摘要/日志维护 | **lite** | 文献收集、数据核对、文档排版 | 低 |
| 代码实现/调试/制图/自动化脚本 | **default（强模型）** | app.py/viz 模块开发、bug 修复 | 中 |
| 复杂方案设计/架构权衡/难 bug 根因 | **reasoning** | 架构决策、疑难杂症（按需启用） | 高 |

- **一键调度模板**（派单时照抄，改 description/prompt/model 即可）：
```json
{"subagent_type":"general-purpose","model":"lite","run_in_background":true,
 "name":"doc-worker","prompt":"<自包含任务书：目标文件绝对路径+验收标准+禁改范围>"}
```
- **固定协作编队**（沿用本次验证有效的模式）：lead(你对话的AI) + scout(Explore只读侦察) + builder(代码) + writer(文档) + verifier(独立复核)；简单整理类单发 lite 即可，不必组队。
- **成本纪律**：高级版 9000 积分至 2026-11-27——日常检索/整理一律 lite，组队仅在多文件并行时启用。
