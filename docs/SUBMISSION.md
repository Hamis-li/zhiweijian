# 知危鉴 · 1024 造物挑战 投稿说明提纲

> 用于填写 `workbuddy.link/p/...` 投稿页，一页讲清"是什么、为什么强、怎么跑的、下一步"。

## 一句话定位
**知危鉴 ZhiWeiJian**（主品牌）— 面向应急管理的「风险预警 + 案例复盘」智能平台；
**CaseRescue 知灾析策**（子品牌）是其应急案例知识引擎。
把原 Coze 版"灾害关键词问答 → 知识卡片"升级为「数据 → 风险识别 → 分级预警 → 态势展示 → 案例复盘 → 决策支持」闭环的可上线 Web 应用。

## 作品亮点（对应评审关注）
1. **从问答到闭环**：不止回答"这个灾害是什么"，还能"识别某区域风险等级 + 出预警 + 给处置建议"。
2. **风险识别引擎**：按灾害类型（洪涝/地质/火灾/台风）多维度加权评分，自动定级（蓝/黄/橙/红）并输出处置建议；权重与阈值可配。
3. **预警机制**：监测指标 × 可配置规则实时匹配分级，支持 5 类指标、四级预警。
4. **案例复盘**：内置 5 份官方事故案例结构化知识卡片，关键词检索（概况/风险因素/措施/教训），保留教育场景。
5. **可上线、可扩展**：前后端分离 + Docker 一键全栈，接口契约清晰，样例数据可平滑替换为真实数据源/向量 RAG。

## 技术栈
- 前端：原生 Web 单页 + ECharts（可演进 React+Vite+TS）
- 后端：Python 3.11 + FastAPI + Pydantic（OpenAPI 3.0）
- 部署：Docker + docker-compose（Nginx 网关单端口托管 + 反代 /api）
- 数据：内置样例 → PostgreSQL/TimescaleDB/Redis/向量库（演进）

## 演示路径（30 秒讲清）
1. 打开 → 仪表盘：KPI（预警 5 / 重大 2 / 指标 4 / 案例 5）+ 风险柱状图 + 趋势图
2. 风险识别：选"洪涝 + A 区"打分 → 引擎返回 71.5 / 橙色预警 + 处置建议
3. 预警中心：降雨 142mm ≥120 → 红色；边坡位移 → 橙色；规则表一目了然
4. 案例复盘：搜"瓦斯/爆炸/化工" → 结构化知识卡片
